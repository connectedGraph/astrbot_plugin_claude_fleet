# 最终质量检查

所有适用检查通过后再交付。

## 内容与教学质量

- 检查讲义是否体现了对主题的独立理解和教学重构，而不是机械复述、压缩或拼接原始资料；不要把逐句忠于资料当作质量标准。
- 检查核心概念、事实、公式、代码、案例和结论是否正确，重要前提、适用范围、限制和推理边界是否完整。
- 检查内容结构是否符合默认受众（高中生与大学生）的学习目标和要求的深度，主要概念是否形成从动机、直觉、机制和证据到边界与结论的教学闭环。
- 检查原始资料中一带而过、默认读者已知或没有讲清，但对主线、后续内容或关键结论重要的概念、前提和推理步骤是否已经充分展开；不能因为来源讲得简略就保留教学断层。
- 检查章节之间是否逻辑连贯，概念是否在使用前得到必要解释，是否仍有重复、跳步、含糊表达、无依据扩写或没有教学价值的材料堆叠。
- 检查资料之间的重要冲突、疑似错误和时效性问题是否已得到合理判断。只有写作过程中确有必要的疑点才需要联网核实，不要为了完成 QA 配额而搜索。
- 检查实际采用的联网资料是否可靠，并已在相关内容附近自然附上可读来源和可点击链接；没有使用联网资料时，不要求为了形式完整而添加。
- 对照 `teaching-reconstruction.md` 重新阅读最终成品，确认各章小结和最终综合准确覆盖正文，并真正帮助读者建立整体理解。

## 编译完整性

- 不存在 LaTeX 错误、缺失宏包、缺失字体、缺字或缺失图片。
- 最终 PDF 每页都有可提取文字，且所有 PDF 字体均已嵌入并带 Unicode 映射。用 `pdffonts` 检查字体嵌入，用 `pdftotext` 抽查可提取文字层；存在缺字、缺字体或文字层缺失时，检查 `.tex` 的字体设置与编码并修复。视觉上有字不能替代可搜索、可复制的文字层。
- 最终一轮构建后，不存在未解析的引用、交叉引用、目录项或参考文献条目。
- cloudtex 交付路径上的 PDF 必须来自最近一次成功的构建，不能拿中间产物或手工编译的 PDF 替代。

## 版面完整性

- 检查封面背景色是否与讲义主题、受众、内容气质和主视觉协调，标题、署名与日期是否保持清晰对比；确认当前项目的封面配色没有改变正文颜色。
- 结合日志中的 `Overfull`/`Underfull` 警告，修复所有可见溢出、过松间距和异常空白。
- 不存在文字裁切、对象重叠、意外空白页、孤立标题或与正文分离的来源标签。
- 表格、代码、公式、图注和提示框均完整位于页面内。
- 写作和排错阶段按风险渲染已修改页面、复杂页面和日志指出的可疑页面。最终交付版本必须在最后一次内容、素材或样式修改并重新构建后，用当前环境可用的方式覆盖检查全书版面（渲染页面图抽查或逐页阅读）。
- 最终版本之前的排错轮次，局部修改后复查受影响页面及必要的相邻页；只有修改影响分页、全局样式、模板或字体时，才在该中间轮次重新覆盖全书。
- 视觉文件存在或命令成功不代表检查通过；必须根据实际看到的内容确认没有裁切、重叠、异常空白或不可读内容。视觉材料是按需生成的临时衍生物，不属于交付成功条件。

## 插图完整性

- 每张裁图都包含需要的标签、图例、边框、图注和公式编号。
- 每张最终采用的模型生成图都已实际检查，图中主体、数量关系、文字、符号和教学含义没有明显错误。
- 模型生成图已明确作为教学示意图使用，没有伪装成原始资料截图，也没有附上虚假的页码、时间或 ReadOS 来源跳转。
- 最终栅格图在实际排版尺寸下具有足够的有效 DPI。对文字较多的素材，将 220 DPI 视为实用警戒线，并检查所有低于该值的图片。

## 来源完整性

- 每个可见来源标签都与实际页码、时间、行号、图片或 URL 一致。
- 每个启用的 `readex://` 链接都能解析，并指向真实工作区资源。
- 存在相应类型时，至少测试一个 PDF、文本和普通文件链接。
- 移动或重命名来源后，最终 PDF 中由 App 补全的稳定链接仍应解析；模型编写的原始路径只作为构建输入和恢复回退，不应要求人工搬运内部身份。

## 交付整洁性

- 只交付一个最终 PDF；不向调用方返回 TeX 源码、素材或项目包。
- TeX 源码和正式素材保留在项目目录中；ReadOS 在 App 私有状态中维护讲义身份、构建和来源信息。
- 模型需要查看的预览图、按需页面图和联系表放在 `/tmp/readex-lecture/` 下的语义目录中；cloudtex 只返回最终 PDF。
- TeX 源码、PDF 元数据、PDF 可见文字和交付文件名中不得出现宿主文件系统路径或密钥。
- 最终交付以 cloudtex `--output` 写入的 PDF 为准，且必须通过上述适用检查。
